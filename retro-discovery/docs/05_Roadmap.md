# Entwicklungsphilosophie

Retro Discovery entsteht nicht durch das zufällige Hinzufügen neuer Funktionen.

Jede Erweiterung verfolgt das Ziel, das Gesamterlebnis der Discovery-Station zu verbessern.

Jedes neue Modul durchläuft die gleichen fünf Phasen:

Concept

↓

Design

↓

Integration

↓

Polish

↓

Release

Erst wenn eine Phase abgeschlossen ist, beginnt die nächste.

# Definition of Done

Eine Funktion ist fertig, wenn sie:

- zur Projektvision passt,
- der Design Language entspricht,
- architektonisch sauber integriert ist,
- dokumentiert wurde,
- auf Desktop, Tablet und Smartphone funktioniert,
- sich wie ein natürlicher Bestandteil der Discovery-Station anfühlt.

"Fertig" bedeutet nicht nur technisch funktionsfähig, sondern qualitativ abgeschlossen.
